# Green Atlas

Приложение для размещения деревьев и кустарников по чертежам AutoCAD.
Проверяет ограничения участка, показывает рост растений в 3D и формирует
чертёж с ведомостью посадок.

**Windows: 0.1.133 — рекомендуемая; 0.1.134 — новейший кандидат, замечен сбой 3D.**
