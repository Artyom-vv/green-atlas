# Зелёный контур

Модульное DXF-рабочее пространство для проверяемого проектирования озеленения.

Граница продукта — любой входной DXF: файл может содержать другие названия слоёв,
локальную систему координат, неполную границу и смешанные типы CAD-геометрии.
ВДНХ используется только как крупный нагрузочный fixture для проверки производительности;
ни один пользовательский сценарий или контракт не привязан к этой территории.

Текущий сценарий читает ASCII- и binary-DXF с CAD-стилями, текстами, блоками и MINSERT-массивами; показывает исходную геометрию в непрерывном canvas; позволяет выбрать несколько реальных замкнутых контуров или обвести собственные; а затем вручную разместить, передвинуть и удалить деревья или кустарники. Проверяются только подтверждённые правила из текущего реестра, а источник, который не позволяет безопасно определить подтип препятствия, остаётся видимым контекстом. Внешние растровые и PDF/DWF/DGN-подложки не подменяют подоснову. В результате экспортируется исходный DXF с отдельным слоем посадок. Полная граница и список сознательно вырезанных функций — в [актуальной границе продукта](docs/current-product-boundary.md).

## Состав

- `apps/web` — React-приложение и предметные UI-компоненты.
- `apps/api` — FastAPI-монолит с ezdxf-импортом, Shapely-геометрией и заменяемыми портами.
- `packages/ui` — независимая дизайн-система «Технический атлас».
- `packages/api-client` — OpenAPI-типы и HTTP-клиент.
- `fixtures` — тестовые данные сквозного сценария.
- `docs` — архитектура и правила зависимостей.

## Запуск

```bash
pnpm install
cd apps/api
uv sync --group dev
uv run uvicorn app.main:app --reload --port 8000
```

Во втором терминале из корня:

```bash
pnpm dev:web
```

Web-приложение ожидает API на `http://127.0.0.1:8000`. Откройте `http://127.0.0.1:5173/projects/new/import` и используйте `fixtures/site.dxf`. Для нагрузочной проверки есть `fixtures/large-map/vdnkh-large.dxf`; это только большой чертёж, а не преднастроенная территория или источник правил.

## Проверки

```bash
cd apps/api && uv run --group dev pytest
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm storybook:build
pnpm test:e2e
pnpm test:e2e:headless
pnpm generate:api
```

`generate:api` экспортирует OpenAPI из FastAPI/Pydantic и заново создаёт `packages/api-client/src/schema.d.ts`. Сгенерированный файл не редактируется вручную.
