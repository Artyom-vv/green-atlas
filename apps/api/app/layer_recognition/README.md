# Распознавание слоёв

Модуль предлагает категории и роли слоёв CAD-захвата. Он не подтверждает
характеристики инженерных сетей и не рассчитывает посадки.

## Ответственность

- `service.py`: координация проходов, конфликтов, сохранения и возобновления.
- Локальный первый проход: однозначные признаки и предложения без внешнего вызова.
- Провайдеры: запрос в разрешённой схеме и проверка ответа.
- `checkpoints.py`: сохранённое основание, принятые ответы и продолжение.

Полные контракты входа/выхода принадлежат коду модуля. HTTP только предоставляет
текущий результат, состояние и поток событий.

## Приватность и смысл

Перед внешним вызовом идентификаторы заменяются псевдонимами. Передаются только
разрешённые количества, типы, признаки названий и сводки подписей. Сырые имена,
полный CAD-текст, пути, handles и свободные объяснения ответа не отправляются.
Проверяются размер, схема, категории, псевдонимы и соответствие запросу.

Подписи — слабый контекст. DN не равен доказанному наружному диаметру;
близость текста не доказывает его принадлежность сети. Неизвестные параметры
не заполняются по догадке. Физическая роль и намерение подготовки границы
различаются. Подтверждённые оператором назначения не перезаписываются автоматически.

## Состояние и кеш

Ключ включает исходные признаки, семантическое основание и версии политики.
Обновление второго прохода меняет ключ; назначенная роль не подменяет исходный признак.
Продолжение связывается с тем же исходником и проверенными checkpoint.
Уже принятые ответы не запрашиваются повторно вслепую.

Завершение первого прохода не означает завершения уточнений и записи.
Текущий этап, активные слои и сохранение имеют отдельные состояния.
Читающий `/status` не создаёт новое задание. При потерянном ответе команды
сначала читается состояние; автоматический повтор POST не выполняется.

## Проверка

Профильные тесты находятся в `apps/api/tests/test_layer_recognition_*.py`,
`test_anonymous_layer_features.py` и тестах семантики. Они проверяют утечки,
подмену основания, конфликты, неполноту, сохранение и возобновление.
Тестовый проход не является измерением экспертной точности на всех чертежах.
