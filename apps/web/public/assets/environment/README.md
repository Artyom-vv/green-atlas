# 3D environment lighting

`kloofendal_48d_partly_cloudy_1k.hdr` is the 1K HDR distribution of
“Kloofendal 48d Partly Cloudy” by Dimitrios Savva and Jarod Guest, downloaded
from Poly Haven.

- Source: https://polyhaven.com/a/kloofendal_48d_partly_cloudy
- License: CC0 1.0 Universal
- Source file URL: https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/1k/kloofendal_48d_partly_cloudy_1k.hdr
- SHA-256: `5477b7dbb2aea4a6947cb36b96339c119f90bf36a03b039af3254b5e6a22896d`

The environment is used through Three.js `PMREMGenerator`. It provides image
based lighting only; it is not shown as fake project context or geography.
