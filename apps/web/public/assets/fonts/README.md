# Noto Sans: локальный fallback текста CAD

`NotoSans-Regular.ttf` — неизменённый шрифт Noto Project под SIL OFL 1.1.
Лицензия и copyright включены в `OFL.txt`. Это отдельный локальный CAD fallback,
а не изменение типографики интерфейса или воспроизведение всех исходных CAD-стилей.

Источник: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
Лицензия: https://github.com/notofonts/noto-fonts/blob/main/LICENSE
SHA-256: `b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`.

Размер: 569 208 байт; 3748 глифов. Локальный opentype-разбор подтвердил
наличие А–Я, а–я, Ё/ё, цифр, знаков ° и ±.

Шрифт из пользовательского датасета и Windows Arial в продукт не копировались.
