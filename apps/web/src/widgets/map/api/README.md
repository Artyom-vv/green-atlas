# Запрос геометрии видимой области

`useViewportGeometry` владеет временем запроса и React Query. API-запрос
предоставляет `entities/source-data/api/readViewportGeometry`; геометрический
буфер и проверка покрытия — чистые функции `model/viewportRequest`.

Отложенный запрос запускается только для последней области после завершения
cancelQueries. Cleanup проекта удаляет debounce и его pending-идентичность.
AbortSignal передаётся API, поэтому поздний ответ предыдущего запроса не
заменяет данные текущей области. Placeholder сохраняет геометрию только того
же проекта и её прежний `loadedGeometryVersion` до успешной замены.

Четыре теста проверяют обратный порядок завершения отмен, смену проекта в
debounce/cancel/network, placeholder версии и отмену транспорта с поздним
успешным ответом. Они используют публичную entity-границу без импорта
API-клиента в widget.

`loadedGeometryVersion` обозначает контекст клиентского запроса. Существующий
GeometrySnapshot не содержит собственной серверной geometry_version, поэтому
это поле не доказывает версию серверного снимка. Этот предел старого API
сохранён и не замаскирован новым контрактом.
