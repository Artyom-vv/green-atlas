# UI 3D-предпросмотра

`SceneReview` сохраняет единственный вызов `useSceneRenderer`, canvas/ref,
публичный handle и состояние окна данных. Управление камерой вынесено в
`SceneCameraControls`, возраст — в `SceneForecastControl`, загрузка и ошибки
— в `SceneStatus`. Дочерние компоненты получают callbacks и значения, не
создают renderer и не импортируют Three-контроллер.

`SceneDataDialog` и `SceneHoverCard` остаются существующими поверхностями.
`SceneResourceDiagnostics` — FC без props; подписка useSyncExternalStore
сохраняется вне lazy-сцены и позволяет наблюдать освобождение ресурсов.

Отрисовка не перезапускается при перемене возраста, выделения или размеров.
Сохранены hidden-состояние, названия контролов, коэффициенты zoom, telemetry,
положение слоёв и сообщения о предыдущем прогнозе. Boolean-условия без
альтернативы записаны через &&.

Проверено 48 случаев сцены: 18 SceneReview, 16 контрактов, 5 геометрии,
5 загрузки моделей и 4 picking. В том числе 20 циклов 2D ↔ 3D и баланс
создания/освобождения контроллеров, повтор после ошибок моделей и WebGL.
