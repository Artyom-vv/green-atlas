# Окна рабочего редактора

`WorkspaceReadyView` собирает IDE-области; `WorkspaceDialogs` собирает окна в
прежнем DOM-порядке. У каждого окна отдельный именованный Props-интерфейс,
производный от нужных полей модели. `PropsFor` принимает собственный узкий
контракт и выбирает только его поля. Модель сохраняет черновики и команды;
извлечение окна не создаёт дополнительный Zustand-store или форму.

| Окно | Ответственность и возврат |
| --- | --- |
| Area | Осмотр области; существующий участок переводит в заполнение, исходная геометрия — в проверку нового участка |
| ZoneReview | Preview границ; отдельные перерисовка, отмена и сохранение через уже существующие команды |
| Library | Выбор посадок и переход к назначению пород; сохраняет текущие идентификаторы |
| ZoneManager | Управление участками; keepMounted при рисовании, подтверждении и удалении |
| Species | Назначение и каталог; keepMounted, скрывается на время review |
| PlanReview | Осмотр, отмена и применение одного текущего preview |
| Release | Восстановление сохранённого пакета, текущая RHF-форма, файлы и read-recovery |
| ToolCancel | Явная отмена preview и переход к выбранному инструменту |
| DeletePlantings / DeleteZone | Отдельное подтверждение предметной команды удаления |

`OperationErrorDialog`, `LeaveWorkspaceDialog` и `FinishPlacementDialog` остаются
общими поверхностями workbench. Окно ошибки не закрывается после неуспешного
async reload. Ref-token защищает от двойного чтения и от закрытия нового окна
поздним ответом прежней попытки.

Сохранены open-условия, keepMounted, stableHeight, ключ проекта формы выпуска и
порядок окон. Скачивание делегировано `features/project-release/api/releases`, UI не
импортирует API-клиент. Дополнительных DOM-контейнеров слоты не создают.
