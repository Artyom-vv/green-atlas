# Навигация по документации

Для продукта используйте следующие документы:

1. [Граница текущей сборки](current-product-boundary.md) — что работает сейчас и
   какие ограничения имеет ручной прототип.
   поставке после упрощения.
2. [Архитектура](architecture.md) — актуальное устройство кода.
3. [API](api-contract.md) — актуальный реализованный контракт.
4. [Правила модулей](module-rules.md) — ограничения при доработке.

Папки `audit-*`, `design-research`, старые анализы и материалы Paper — история
исследований. Они не являются спецификацией продукта. Из них нельзя возвращать
в маршрут рейтинг территорий, глобальный ассортимент, постоянные AI-команды и
отдельную таблицу трёх сценариев. Автоматизация возвращается только в форме
локальных предварительных изменений внутри выбранной области и с подтверждением
специалиста.
