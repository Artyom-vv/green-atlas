# Архитектура Green Atlas

Описание актуальной версии в `main`. Код этой архивной ветки может отличаться.

AutoCAD подготавливает CAD-геометрию. Green Atlas хранит проект,
строит ограничения и рассчитывает посадки локально.

## Состав

| Часть | Ответственность |
|---|---|
| `tools/autocad-bridge` | Плагин, захват чертежа, передача и запись CAD-выпуска |
| `apps/api` | Приём данных, хранение, подготовленная геометрия, правила, планирование и выпуск |
| `apps/web` | Исходные данные, карта, посадки, замечания и 3D |
| `packages/ui` | Общие компоненты и токены интерфейса |
| `packages/api-client` | Клиент, сгенерированный по OpenAPI |

## Поток данных

Открытый чертёж → захват AutoCAD → назначения слоёв → подготовленная
геометрия → ограничения → предпросмотр посадок → сохранённый план → выпуск.

Проект хранит связь с захватом, решения по исходным данным, расчётный снимок
и версии плана. Изменение основания расчёта требует обновить зависимые данные.
Сохранение проверяет, что предпросмотр относится к актуальной версии.

## Общая расчётная основа

`PreparedStore` хранит снимок и проверяет целостность.
`ProjectLiveGeometry` выбирает подходящую основу проекта.
`PreparedProjection` предоставляет её потребителям.
`PreparedGeometryEngine` выполняет измерения, а `PlacementPolicy` применяет
правила посадки.

Ручная и автоматическая посадка, сохранение, повторная проверка и паспорт
используют эти общие данные. Упрощённая геометрия карты служит отображению,
а не отдельным источником расчёта.

## Границы модулей

Прикладные сценарии обращаются к внешним системам через порты и адаптеры.
Интерфейс не читает CAD и не дублирует нормативные правила. Планирование
не восстанавливает XREF. CAD-выпуск работает с копией архива исходного захвата.
История и изменения плана сохраняются согласованно.

Нейтральные компоненты находятся в `@green/ui`, предметные — в модулях
`apps/web/src`. Карта сохраняет состояние при переключении панелей.
Типы API генерируются из серверного контракта.

## Контроль

Проверяются целостность передачи, версии оснований, геометрические операции,
предпросмотр и применение, сохранение проекта и повторное открытие выпуска.
Архитектурная проверка не допускает новых зависимостей от старых CAD-парсеров.

Подробные правила: [CAD-контракт](architecture/autocad-contract.md),
[границы модулей](module-rules.md) и [модульная документация](obsidian/README.md).
