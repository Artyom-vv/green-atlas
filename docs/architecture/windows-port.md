# Windows: архитектура версии 0.1.133

Windows использует общие Web, API, модели проекта, правила, локальный проверяющий
модуль и историю. Платформа не выбирает другой алгоритм и не снижает полноту проверок.

| Подсистема | Граница Windows |
|---|---|
| Окно | Win32, WebView2, системные диалоги, поколения документа |
| Локальный API | Встроенный runtime, приватный сеанс, собственный Job Object |
| Передача | Билет, private named pipe, ACL текущего пользователя |
| AutoCAD | ARX/CRX для 2027, подготовка и выпуск по общим контрактам |
| Профиль | LOCALAPPDATA, блокировки файлов, согласованная запись и восстановление |
| 3D/рендер | Общая сцена; отдельный Blender EXE и локальные ресурсы |
| Поставка | Обычный пользователь, Setup, manifest, ярлыки, обновление и удаление |

Профиль `%LOCALAPPDATA%\GreenAtlas` содержит Workspace, Transfers, WebView2
и Logs. Настройки внешних компонентов отдельно находятся в
`%LOCALAPPDATA%\Green Atlas\external-tools.json`.

Обновление сохраняет данные. Ошибка блокировки файла не обходится повышением
прав или принудительным завершением чужого процесса. Core cleanup допускается
только для собственного задания после проверки результата по
[CAD-контракту](autocad-contract.md).

Наличие Windows-кода и сборка EXE не доказывают сквозную работу.
