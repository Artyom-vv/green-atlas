# Термины

| Термин | Значение |
|---|---|
| CAD-подоснова | Чертёж с исходными объектами территории |
| DWG / DXF | Форматы чертежей; в основном сценарии их читает AutoCAD |
| XREF | Внешняя ссылка чертежа на другой файл подосновы |
| Блок | Группа CAD-объектов, размещённая в чертеже одним или несколькими экземплярами |
| Слой | Именованная группа объектов чертежа |
| Назначение слоя | Тип содержимого и способ его учёта при расчёте |
| Захват | Состояние объектов AutoCAD с единицами, происхождением и диагностикой |
| Подготовленная геометрия | Сохранённые области, отверстия, линии и точки с известной точностью |
| Область | Замкнутая геометрия с внутренней площадью |
| Линейный остаток | Читаемая линия, для которой не подтверждена внутренняя область |
| Пропуск | Объект или ссылка, геометрия которых недоступна для требуемой проверки |
| Полнота данных | Учёт доступных, восстановленных, линейных, исключённых и недоступных объектов |
| Расчётная граница | Граница территории проекта |
| Рабочий участок | Выбранная пользователем часть территории для посадок |
| Отступ | Минимальное расстояние, используемое выбранным правилом |
| Область поиска | Часть рабочего участка после вычитания принятых ограничений |
| Кандидат | Пробная позиция растения до принятия алгоритмом |
| Принятая позиция | Кандидат, прошедший проверку и занявший место в текущем варианте |
| Рабочее допущение | Явный параметр расчёта при недостатке данных; не подтверждённая норма |
| Предпросмотр / preview | Предложенные изменения без записи в сохранённый план |
| Применение / apply | Проверка актуальности предпросмотра и сохранение изменений |
| Ревизия | Версия состояния проекта, плана, правил или исходных данных |
| Выпуск | Создание выходных файлов; не равнозначно сохранению проекта |
