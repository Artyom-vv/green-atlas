# Назначение продукта

Green Atlas — локальный инструмент проектирования озеленения по CAD-подоснове.
Проектировщик выбирает участок, размещает растения, проверяет ограничения
и получает план для дальнейшей работы в CAD.

## Основные действия

- Передать открытый чертёж из AutoCAD.
- Проверить исходные данные и назначения слоёв.
- Выбрать участок и растения.
- Расставить посадки вручную или принять автоматическое предложение.
- Исправить замечания, сохранить план и выпустить результат.

У каждого действия есть видимый результат: подготовленная карта,
предпросмотр, сохранённая версия или готовый файл. Технические подробности
открываются по необходимости и не заменяют основное действие.

Функции и ограничения описаны в [границах продукта](current-product-boundary.md).
Порядок работы и модули — в [документации сервиса](obsidian/README.md).
