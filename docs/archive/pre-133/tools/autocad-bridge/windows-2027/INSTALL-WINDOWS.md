# Установка Green Atlas для Windows

Запустите EXE установщика Green Atlas из комплекта двойным щелчком из обычного
профиля Windows. Перед установкой закройте AutoCAD и Green Atlas. Не выбирайте
«Запуск от имени администратора»: установка предназначена для текущего пользователя.

Пройдите мастер: «Далее», папки программы и проектов, выбор ярлыка рабочего
стола, «Установить». Окно показывает текущий этап. На странице завершения
оставьте «Запустить Green Atlas» и нажмите «Готово». В дальнейшем программа
доступна через «Пуск → Green Atlas» и выбранный ярлык рабочего стола.

Программа и плагин находятся в
`%APPDATA%\Autodesk\ApplicationPlugins\GreenAtlas.bundle`.
Проекты находятся отдельно в `%LOCALAPPDATA%\GreenAtlas\Workspace` и сохраняются
при обновлении и удалении. Для удаления используйте «Параметры → Приложения →
Green Atlas → Удалить». Повторный запуск установщика обновляет или восстанавливает
программу. AutoCAD и Blender для проверки установки и запуска окна не требуются.

Мастер использует [Inno Setup](https://jrsoftware.org/); дополнительно устанавливать
его на компьютер не нужно.

Setup содержит программу, Web, автономный API, оба плагина AutoCAD, CRT и полный
офлайн-установщик Microsoft WebView2. Python, Node, PowerShell, SDK и исходники
для использования не нужны. Этот кандидат не подписан сертификатом издателя;
Windows может запросить подтверждение запуска скачанного приложения.

Если WebView2 уже установлен для всех пользователей и устарел, Setup предложит
обновить его через стандартный запрос Windows UAC. Права администратора нужны
только включённому установщику Microsoft; Green Atlas продолжит установку
в обычном профиле. При отмене обновления установка приложения не завершается.

После установки откройте Green Atlas из меню Пуск. В установленном AutoCAD 2027
для Windows x64 откройте рабочий DWG/DXF и вызовите `GAOPEN`. AutoCAD может
запросить доверие к новому плагину. Подготовка чертежа, расчёты и сохранение
происходят локально. Исходный чертёж не перезаписывается.

На шаге «Компоненты и ресурсы» мастер ищет AutoCAD и Blender. Для нестандартной
установки нажмите «Выбрать…». При необходимости выберите шаблон AutoCAD `.dwt`.
Подключите имеющиеся каталоги Botaniq и PBR. Мастер проверяет нужные модели и
текстуры; самих библиотек в Setup нет. Каталог Botaniq должен содержать
`blends_280` и `textures`; допускается выбрать родительскую папку пакета.

Пустые поля позволяют подключить компоненты позже. Откройте Green Atlas,
нажмите «Компоненты» в списке проектов или рабочем редакторе. Здесь доступны
повторный поиск, системный выбор файлов и папок, проверка и сохранение.
Редактировать JSON или переменные окружения не нужно. Новые задания читают
сохранённые пути без перезапуска приложения; выполняющееся задание не меняется.
Отмена мастера не сохраняет настройки, обновление и удаление программы их
сохраняют. Проверка файлов библиотеки не заменяет проверку настоящего рендера.

На чистом профиле кеш моделей просмотра ещё не создан. Запустите «Рендер»
из подготовленного проекта, дождитесь подготовки моделей, затем обновите 3D.

Проверьте на своей машине:

1. Запуск из меню Пуск, `GAOPEN`, передачу и подготовку чертежа с XREF.
2. Ручные и автоматические посадки, сохранение и повторное открытие проекта.
3. Проверку, паспорт и CAD-выпуск с открытием результата в AutoCAD.
4. Просмотр 3D, подготовку моделей и Blender render с имеющейся библиотекой.
5. Повторный запуск Setup для обновления или удаления; рабочие проекты и модели
   должны сохраниться.

Подробное описание путей и внешних ресурсов находится в исходниках:
`docs/obsidian/05 Эксплуатация/Установка и проверка Windows.md`.
Сборочная квитанция указывает точный Git commit, SHA256 Setup и границы
автоматической проверки. Загрузка плагинов в AutoCAD, настоящий WebView2 UI
и Blender render требуют этой приёмки на целевой машине.
