# Green Atlas: профиль интерфейса

Описание актуальной версии в `main`. Код этой архивной ветки может отличаться.

## Пользователь и задача

Проектировщик работает с CAD-подосновой, выбирает участок и размещает растения.
Основные объекты: исходный чертёж, слой, участок, посадка, замечание и версия плана.

## Рабочий путь

1. Открытие чертежа из AutoCAD.
2. Проверка источника и назначений слоёв.
3. Выбор участка и растений.
4. Ручное размещение или автоматическое предложение.
5. Проверка, сохранение и выпуск.

Карта — постоянное рабочее пространство. Слева находятся данные проекта,
справа — активный инструмент или свойства. Переключение панелей сохраняет
центр, масштаб и выбор. 2D и 3D показывают один план.

## Правила взаимодействия

- Одно основное действие на текущем шаге.
- Сначала результат и причина, подробности по запросу.
- Замечание ведёт к объекту или месту на карте.
- Предпросмотр отделён от сохранённых изменений.
- Состояния загрузки, ошибки и отсутствия данных различимы.
- Закрытие панели не означает отмену сохранённого плана.

## Технические ограничения

- Русский интерфейс, основной формат — настольное приложение.
- Проверка компоновки на ширинах 1024–1920 px и клавиатурной навигации.
- Карта скрывает OpenLayers за `MapViewport`.
- Расчётные правила находятся на сервере, не в компонентах карты.
- Типы API генерируются из OpenAPI.
- Компоненты и токены переиспользуются из `@green/ui`.
