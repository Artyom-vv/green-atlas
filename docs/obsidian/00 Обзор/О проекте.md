# О проекте

Green Atlas — локальное приложение для проектирования озеленения по CAD-подоснове.
Проектировщик выбирает растения и участок, проверяет размещение и выпускает
отдельный чертёж с ведомостями.

| Часть | Назначение |
|---|---|
| Плагин AutoCAD | Передача открытого DWG/DXF и доступных подоснов |
| Локальное приложение | Исходные данные, посадки, проверки и хранение проектов |
| 3D и рендер | Просмотр окружения, роста и выбранного ракурса |
| CAD-выпуск | Копия чертежа с посадками, ведомости и сведения о проверках |

Новый проект создаётся через AutoCAD. Python, Node.js и репозиторий для
установки готового приложения не нужны. Дополнительные модели и рендер
используют Blender и локальные библиотеки.
