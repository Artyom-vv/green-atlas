# О проекте

Green Atlas сокращает разрыв между CAD-комплектом и проверяемой схемой озеленения. Для production-потока AutoCAD открывает корневой DWG/DXF и доступные package-local XREF только на чтение; сервис принимает допущенный native snapshot, после чего оператор отдельно подтверждает смысл слоёв, выбирает области и выпускает результат.

## Что входит в продукт

- native extraction из AutoCAD/ObjectARX с coverage каждой instance;
- read-only открытие DWG/DXF и package-local XREF без повторного DXF-read/write;
- SHA-256 корневого чертежа, XREF и payload;
- просмотр CAD-геометрии и сопоставление слоёв;
- выбор существующих контуров или ручное построение рабочей области;
- одиночное и групповое размещение деревьев и кустарников;
- предварительная проверка изменений до применения;
- проверка подтверждённых пространственных ограничений;
- назначение ревизий пород и просмотр горизонтов роста;
- 3D-предпросмотр;
- выпуск DXF, ведомости, дендроплана, сцены и manifest после независимых стадий расчёта.

## Что не входит

- повторное чтение native-production-геометрии ezdxf как источника расчёта;
- автоматическое нормативное согласование;
- выдача порубочного билета или заключения;
- признание неизвестного слоя безопасным;
- городское ранжирование территорий;
- автоматическое изменение проекта без preview и подтверждения;
- гарантированная поддержка всех версий AutoCAD и всех CAD-сущностей.

## Технологический состав

| Часть | Реализация |
|---|---|
| Веб-приложение | React 19, TypeScript, OpenLayers, Three.js |
| API | FastAPI, Pydantic |
| CAD production | AutoCAD/ObjectARX, native snapshot и admission |
| DXF | обменный/выпускной формат; legacy и не production source of truth для native flow |
| Геометрия | Shapely |
| Хранение | SQLite |
| Контракты | OpenAPI и генерируемые TypeScript-типы |
| Развёртывание | Docker Compose, Nginx, AdminVPS |

## Основной пример

Основной рабочий пример — Кустанайская улица. ВДНХ и Китай-город используются как крупные fixtures для нагрузки и проверки геометрии, но не задают предметную модель продукта.
