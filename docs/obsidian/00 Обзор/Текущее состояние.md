# Текущее состояние

## Область версии

В публичном main опубликованы Mac-пакет 0.1.45 и отдельный Windows-пакет
0.1.42. Оба содержат приложение, локальный сервис и плагин для полного
AutoCAD 2027; исходный CAD-комплект Кустанайской общий.
Mac-пакет рассчитан на Apple Silicon и macOS 14 или новее, Windows-пакет —
на Windows 11 x64 с Microsoft Edge WebView2 Runtime.
Старые установленные сборки нужно обновить целиком.

Основной код main соответствует Mac-контрольной точке. Windows-исходники
находятся в отдельной ветке разработки: публикация готового Windows-ZIP
не означает объединения исходников платформ.
Результаты отдельных версий и пределы приёмки приведены в
[[04 Качество и показатели/Качество и показатели]].

## Возможности

| Возможность | Статус | Граница |
|---|---|---|
| Передача открытого чертежа из AutoCAD | Реализована | Требуется совместимый плагин и доступ к исходнику |
| Чтение подоснов | Частично | Недоступные ссылки и неподдержанные объекты дают замечания |
| Назначение типов слоям | Реализовано с автоматическим применением | Поддерживаемые однозначные роли принимаются автоматически, спорные остаются на проверке; ручные решения сохраняются |
| Распознавание слоёв Luna | Предложения для комплектной Кустанайской включены | Для неизменённого исходника ключ не нужен; живой запрос для другого чертежа требует настройки провайдера |
| Восстановление составных областей | Реализовано с ограничениями | Не вся читаемая линия образует подтверждённую площадь |
| Расчёт по сохранённой геометрии | Реализован | Для новой подготовки и CAD-коррекции нужен AutoCAD |
| Ручная посадка и автоматический подбор | Реализованы | Результат ограничен данными, правилами и бюджетом поиска |
| Сохранение и повторное открытие проекта | Реализованы | Локальное сохранение не создаёт CAD-комплект |
| Карта и 3D | Есть в приложении | 3D не подтверждает расчётную точность |
| Внешняя модель для агента | Требует настройки и отдельной проверки | Не обязательна для основного сценария |
| Выпуск DWG для проекта из открытого AutoCAD | Реализован | ZIP с доступными XREF; первая архивация требует действующего захвата |
| Поддержка произвольных больших исходников | Ограничена | Размер передачи и потребление памяти ограничены |
| Распространение на Windows | Готовый отдельный пакет, проверен на стенде | Установка на чистой Windows-машине пока не принята; требуется WebView2 |

Mac 0.1.45 содержит клиент серверного Luna-прокси, но URL и личный токен
не настраиваются установщиком. Windows 0.1.42 этого клиента не содержит.
Серверный код остаётся в рабочем dev и не входит в публичный main.
Готовые предложения в обоих архивах не являются новым запросом модели.
Обычный маршрут Кустанайской доступен без Codex и ключа OpenAI.

## Интерфейс

Назначения расчётной границы согласуются с типами слоёв; ошибки указывают слой
и причину. Исходные данные собраны в раскрывающиеся панели.
Подготовка показывает этапы и счётчики, но первичная обработка большого
чертежа по-прежнему может быть долгой.

Газоны, покрытия и здания различаются цветом и объясняются легендой.
Счётчики замечаний плана и отдельных посадок группируют повторяющиеся причины.

История основных трудностей и их статусы простым языком:
[[08 Проблемы и решения/Проблемы и решения]].
