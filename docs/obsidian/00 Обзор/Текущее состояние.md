# Текущее состояние

Текущая поставка: **Green Atlas 0.1.133 для Windows x64**, предварительный выпуск.
[Скачать установщик и прочитать примечания](https://github.com/Artyom-vv/green-atlas/releases/tag/v0.1.133-windows).

Дополнительная версия: [0.1.134, новейший кандидат](https://github.com/Artyom-vv/green-atlas/releases/tag/v0.1.134-windows-candidate).
Содержит оптимизации CAD и исправление адресов Web-ресурсов. Проверены установка,
повторный запуск, обновление и удаление; полного прогона AutoCAD и Blender не было.
Возможна нестабильность. 133 остаётся рекомендуемой версией с большим объёмом проверок.

## Поддерживаемый комплект

| Компонент | Версия / условие |
|---|---|
| ОС | Windows 11 x64 |
| CAD | Полный AutoCAD 2027 x64 |
| GUI-плагин / Core worker | 0.1.48 / 0.1.49 в составе установщика |
| Детальные модели и рендер | Blender 4.5 LTS, локальные Botaniq/PBR |

Windows 10, AutoCAD LT и другие версии AutoCAD не заявлены для этой поставки.
Наличие macOS-кода не означает наличие квалифицированного установщика Mac 133.

## Возможности

- Захват открытого DWG/DXF, доступных XREF и замечаний исходника.
- Назначение слоёв, подготовка геометрии, рабочие участки.
- Ручная и автоматическая посадка, предпросмотр и применение, Undo/Redo.
- Проверка отступов, существующих растений и выбранного горизонта роста.
- 2D/3D, геопривязка, здания OSM, локальный рендер выбранного ракурса.
- Сохранение проекта и отдельный CAD-выпуск.

## Границы подтверждения

Установка, обновление и сохранность данных проверены на Windows. Проверка
подготовки CAD включает исходный runtime и чтение результата упакованным runtime;
это не полный сценарий через установленное окно приложения.
Реальный Windows-рендер Blender и отдельная полностью кириллическая учётная
запись не прошли сквозную приёмку выпуска 133.

Неполная геометрия остаётся замечанием. Набор реализованных правил не означает
полного соответствия всем действующим нормативам. Детали:
