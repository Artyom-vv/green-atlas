# Термины

| Термин | Значение |
|---|---|
| XREF | Внешняя подоснова, на которую ссылается чертёж |
| Захват | Сохранённое состояние объектов AutoCAD с происхождением и диагностикой |
| Назначение слоя | Роль объектов: здание, дорога, сеть, растения и другие |
| Подготовленная геометрия | Расчётные области, отверстия и линии с известной точностью |
| Контур отображения | Геометрия для карты; сама по себе не расчётное основание |
| Пропуск | Недоступный объект или XREF, отмеченный отдельным замечанием |
| Рабочий участок | Выбранная часть территории для размещения растений |
| Отступ | Расстояние, заданное правилом для конкретного типа объекта |
| Рабочее допущение | Явное условие расчёта при недостатке данных; не подтверждённая норма |
| Предпросмотр | Предложение изменений без записи в план |
| Применение | Проверка актуальности предложения и сохранение изменений |
| Ревизия | Версия исходных данных, решений, правил или плана |
| Горизонт роста | Выбранное число лет для расчётного размера растений |
| Выпуск | Создание выходных файлов из сохранённого плана |
| Квитанция | Сведения о результате операции и основании её проверки |
