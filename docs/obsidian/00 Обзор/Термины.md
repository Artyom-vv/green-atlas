# Термины

| Термин | Значение |
|---|---|
| Корневой чертёж | Saved DWG или DXF, открытый AutoCAD только на чтение |
| Native snapshot | Допущенный снимок расчётной геометрии, извлечённой AutoCAD/ObjectARX |
| Coverage ledger | Реестр source instances со статусом native, context или unresolved |
| Admission | Независимая проверка протокола, хешей, counts, topology и provenance до использования геометрии |
| Сопоставление слоя | Подтверждённая оператором предметная роль CAD-слоя |
| Рабочая область | Полигон, внутри которого разрешено проектировать посадки |
| Ограничение | Проверяемая геометрическая зона, построенная по подтверждённому правилу |
| Change set | Атомарный набор добавлений, перемещений и удалений |
| Preview | Расчёт результата без изменения проекта |
| Выпуск | Неизменяемый набор результатов, связанный с конкретным состоянием проекта |
| Manifest | Машиночитаемое описание состава выпуска и контрольных сумм |
| Evidence | Код, тест, измерение или документ, подтверждающий утверждение |
