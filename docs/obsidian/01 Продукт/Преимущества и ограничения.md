# Преимущества и ограничения

| Возможность | Что получает проектировщик |
|---|---|
| Подготовка через AutoCAD | Объекты и доступные подосновы из открытого чертежа |
| Общий проверяющий модуль | Согласованные проверки ручной и автоматической посадки |
| Предпросмотр | Проверка варианта до изменения сохранённого плана |
| Горизонт роста | Поиск конфликтов, возникающих при увеличении растений |
| 3D и выпуск | Просмотр сцены и отдельный CAD-комплект |
| Локальное хранение | Проекты и расчёты на компьютере пользователя |

Результат зависит от качества чертежа, назначений слоёв, полноты подоснов
и параметров правил. Программа не восстанавливает отсутствующие сети,
не заменяет дендрологическое обследование и не выдаёт согласования.
Для распознавания слоёв, поиска адресов и получения внешней карты нужен интернет.
