# Преимущества и ограничения

## Подтверждаемые преимущества

| Свойство | Механизм | Практический эффект |
|---|---|---|
| Авторитетная геометрия | AutoCAD читает root и XREF напрямую, без второго production parser | Расчёт не основан на повторной DXF-интерпретации |
| Проверяемая полнота | Coverage ledger разделяет native, context и unresolved instances | Частичная геометрия не выдаётся за полную |
| Проверяемые изменения | Preview и apply разделены; используется digest и версия плана | Устаревший или частично недопустимый набор не применяется молча |
| Воспроизводимость | Детерминированные адаптеры, seed для естественных схем | Повторный расчёт можно сопоставить с исходными условиями |
| Честная неопределённость | Неизвестная сеть получает статус «нужно уточнение» | Отсутствие знания не превращается в ложную безопасность |
| Связанный выпуск | Артефакты привязаны к версии плана и геометрии | Повторное скачивание не подменяется новым состоянием |
| Работа с крупными чертежами | Геометрия выдаётся фрагментами по viewport | Клиент не обязан загружать весь чертёж одновременно |
| Защита параллельных изменений | `If-Match`, `state_version`, ответы 409 | Клиент не перезаписывает чужое состояние незаметно |

## Ключевые ограничения

| Ограничение | Последствие |
|---|---|
| Нормативный реестр неполон | Результат нельзя считать согласованным проектом |
| Неизвестные коммуникации не получают универсальный буфер | Требуется типизация и отдельное основание |
| Семантика не извлекается из геометрии | Слои требуют отдельного пользовательского подтверждения |
| Остаточные объекты не превращаются в геометрию | Они сохраняются как замечания; доступная геометрия может быть использована по явному scope |
| Native flow проверен на одной реальной Mac-конфигурации и одном пакете | Нельзя заявлять совместимость с Windows или всеми улицами |
| Установщик macOS пока ad-hoc signed | Он не готов к публичному распространению |
| Агентный контур не должен обходить подтверждение оператора | Автономное изменение проекта ограничено |
