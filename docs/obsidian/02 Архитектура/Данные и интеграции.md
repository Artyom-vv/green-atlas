# Данные и интеграции

| Данные | Источник и использование |
|---|---|
| CAD-захват | AutoCAD: объекты, XREF, единицы, преобразования, подписи и пропуски |
| Назначения слоёв | Сохранённые роли; распознавание создаёт предложения |
| Расчётная геометрия | Подготовленный снимок: области, отверстия, линии, точность |
| Правила | Версионированная конфигурация отступов, поиска и допущений |
| Растения | 248 позиций из московского ассортимента; отдельные профили размеров и роста |
| План | Посадки, участки, история, ревизии и квитанции изменений |
| Окружение | Подтверждённая геопривязка, сохранённые данные OSM |
| Модели и текстуры | Локальные Botaniq/PBR; Blender готовит ресурсы сцены |

Сетевые обращения нужны для подключённого распознавания слоёв, адресного
поиска и загрузки внешних картографических данных. Полный CAD и расчётная
геометрия не отправляются модели распознавания. Передаются разрешённые
обезличенные признаки слоёв; ответ проверяется по схеме.

Адрес не устанавливает геопривязку чертежа автоматически. Отсутствующая
высота здания OSM не является измеренной высотой.
