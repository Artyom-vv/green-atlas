# Данные и интеграции

## Источники истины

| Данные | Источник истины | Производное состояние |
|---|---|---|
| Расчётная CAD-геометрия | Допущенный native snapshot AutoCAD | Viewport snapshot и ограничения |
| Исходный файл | Read-only DWG/DXF и package-local XREF с SHA-256 | Evidence и coverage ledger |
| Смысл слоёв | Подтверждённые layer mappings | Набор ограничений |
| Рабочая область | Сохранённые planting zones | Маски размещения |
| Посадки | Версионированный plan | 3D-сцена, ведомость, дендроплан |
| История | Change sets и курсор undo/redo | Текущее состояние плана |
| Выпуск | Неизменяемые артефакты и manifest | Ссылка для скачивания |
| Порода | Неизменяемая ревизия каталога | Прогноз по горизонтам |

## Публичные границы

- HTTP API описан в `apps/api/openapi.json`.
- TypeScript-типы генерируются в `packages/api-client`.
- Ошибки имеют единый контракт `code`, `message`, `field_errors`, `details`.
- Изменяющие запросы используют optimistic concurrency через `If-Match`.
- Release bundle использует versioned manifest и контрольные суммы.
- ObjectARX является production-provider расчётной геометрии; rejected native probe не заменяется fallback parser.

## Интеграционный риск

Desktop delivery и browser approval реализованы в коде, но end-to-end в целевой конфигурации отдельно не подтверждены. Native admission подтверждает геометрию, а не правильность semantic mappings или готовность нормативного расчёта.
