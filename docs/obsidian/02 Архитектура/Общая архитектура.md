# Общая архитектура

| Модуль | Ответственность |
|---|---|
| Плагин и AutoCAD Core | Чтение CAD, подготовка областей, отдельный CAD-выпуск |
| Desktop host | Окно приложения, запуск локального API, передача проекта и загрузка файлов |
| Локальный API | Проекты, подготовленная геометрия, правила, расчёт и история |
| Web | Карта, панели, посадки, замечания и Three.js-сцена |
| Blender | Подготовка детальных моделей и рендер |

Поток: **AutoCAD → захват → назначения → подготовленная геометрия →
предпросмотр → сохранённый план → выпуск**.

Подготовленный снимок — общее основание ручной и автоматической посадки,
повторной проверки и паспорта. AutoCAD не запускается для проверки каждой
позиции. Геометрия карты и 3D не заменяет расчётный снимок.

Внешние системы подключены через адаптеры. Интерфейс не читает DWG
и не дублирует нормативные правила. Оболочка Windows использует те же Web,
API и расчёт, что общая кодовая база.
