# Windows desktop host

Windows host использует Win32 и WebView2. Он показывает общий Web-интерфейс
и запускает встроенный локальный API; отдельного Windows-алгоритма посадки нет.

| Владелец | Задача |
|---|---|
| Общие контракты | Переходы, поколения документа, защита незавершённой записи |
| Windows platform | Приватный IPC, процессы, файлы и HTTP |
| Главное окно | WebView2, меню, готовность документа и диалоги сохранения |

Профиль принадлежит текущему пользователю. Передача содержит ID билета,
а не путь, token или произвольную команду. Процессы runtime принадлежат
собственному Windows Job Object.

Загрузки принимаются только из разрешённых маршрутов текущего сеанса,
с проверкой типа и целостности. Внешняя ссылка открывается отдельным действием
без передачи секрета приложения.

Проверки оболочки и установщика не подтверждают полный CAD- или Blender-сценарий.
