# Windows desktop host - проверка интеграции

Дополнение к [[Подготовка Windows и упаковка]]. Изолированный Windows-кандидат
использует тот же Web и desktop-протокол, что Mac. Общий `LeaveCoordinator`
проверяет поколения документа и ID решения, Web сохраняет ответственность
за draft и неизвестный результат записи. Mac-оболочка этим участком не меняется.

## Сбой интерфейса

Windows host обрабатывает WebView2 `ProcessFailed` для browser и главного
renderer, включая зависание. После такого события готовность документа
не объявляется восстановленной при перезапуске API. Старое решение о переходе
и повторный ready не разрешают автоматический переход. Новый POST не повторяется.

До первой готовности документ можно закрыть без подтверждения потери изменений.
Если документ уже был готов, native-диалог позволяет явно подтвердить закрытие
при недоступном подтверждении сохранения. Отказ оставляет окно открытым.
Это не доказательство сохранности незавершённых записей.

## Загрузки и внешние ссылки

Синхронный WebView2 callback не открывает save dialog или системный браузер.
Он сохраняет только plain данные в ограниченную очередь; UI-действие происходит
после возврата callback. Встроенная загрузка WebView2 отменяется сразу.
Перед save dialog и после его завершения повторно проверяются origin, token,
поколение runtime, доступность API и документа. Смена сессии во время выбора
файла не запускает запрос со старым token.

Native HTTP разрешает только текущий origin и известный маршрут загрузки.
Существующая совместимость source-dxf/download сохраняется для старых проектов.
Файл публикуется из отдельного временного файла, квитанция записывается
независимо от других квитанций. Пользовательский DWG не становится целью записи.

## Граница доказательства

На Mac исполняются переносимые C++ политики, включая отбрасывание старой сессии
и решений после потери renderer. Это не компиляция Win32-ветки и не запуск
WebView2. Сборка MSVC, работа диалогов после callbacks, ProcessFailed, Setup
и сквозной путь AutoCAD 2027 требуют отдельной приёмки на Windows.

Основания: [Microsoft, threading model и reentrancy](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/threading-model#reentrancy),
[Microsoft, ProcessFailed](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2#add_processfailed).
