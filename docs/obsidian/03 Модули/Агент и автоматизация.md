# Агент и автоматизация

## Назначение

Подготовить объяснимое предложение действий по проекту, сохраняя контроль оператора и обычные предметные контракты приложения.

## Устройство

Agent runtime хранит run records, предложения, статусы, preview и управляющие команды. Подтверждённое предложение проходит через те же application-сценарии и change-set проверки, что и ручное действие.

## Преимущества

- предложение отделено от применения;
- возможны отмена, продолжение и запрос уточнения;
- состояние запуска сохраняется;
- агент не получает отдельного обходного пути к проекту.

## Ограничения

- внешний model API на развёрнутой площадке не подключён;
- агент не является обязательной частью основного маршрута;
- автономное изменение без подтверждения запрещено продуктовой границей;
- качество предложений требует отдельного набора evaluation и живой приёмки.

**Проверено:** lifecycle и control-flow тестами. **Реализовано, не проверено E2E:** подключение внешней модели на площадке. **План:** отдельная evaluation-программа. **Историческое:** агент не является источником CAD-геометрии и не заменяет AutoCAD admission.
