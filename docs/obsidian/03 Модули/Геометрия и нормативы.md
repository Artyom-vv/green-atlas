# Геометрия и правила

## Назначение

Построить ограничения и проверить позиции по сохранённой геометрии.
AutoCAD отвечает за чтение CAD и восстановление областей. Сервис использует
Shapely для расстояний, отступов, объединения и вычитания областей.

## Вход и результат

| Вход | Результат |
|---|---|
| Подготовленная геометрия и назначения | Измеряемые препятствия |
| Рабочий участок и профиль растения | Область поиска |
| Версия правил и допущений | Применённые расстояния и основания |
| Проверяемая позиция | Результат проверки и объяснение |

Область поиска, измерения и полнота используют одну PreparedProjection.
Проверки выполняются PreparedGeometryEngine и общей PlacementPolicy.

## Порядок работы

1. Проверить актуальность подготовленного снимка.
2. Выбрать правила по типу объекта и параметрам растения.
3. Построить ограничения с учётом погрешности геометрии.
4. Вычесть ограничения из рабочего участка.
5. Передать область поиска планировщику.
6. Проверить предложенные позиции и сохранить основания ответа.

Маски строятся по запросу для участка и параметров растения, затем
переиспользуются. Вся улица не рассчитывается заранее для всех пород.
Подготовленный путь не обходит площадь ячейками с обращением в AutoCAD.

## Конфигурация правил

Источник: apps/api/app/regulations/placement_rules.json.
Ревизия описываемого набора: placement-rules/2026-09-25.1.

| Раздел | Содержимое |
|---|---|
| sources | Документ, редакция, пункт и область применения источника |
| setbacks | Базовые отступы по подробному типу объекта |
| working_geometry | Рабочие допущения при недостатке данных |
| layout | Параметры компоновки растений |
| technical | Численные допуски |
| candidate_search, hybrid_search | Бюджеты и параметры поиска |

В конфигурации указаны 743-ПП и СП 42.13330.2016 с конкретными редакциями.
Наличие ссылки не подтверждает применимость всех положений к конкретному
проекту. Документация сервиса не является нормативной экспертизой.

## Недостаток сведений

При известном типе сети используется доступное базовое правило.
Если численного правила недостаточно, рабочая конфигурация задаёт
допущение 2 м. Это не нормативный отступ и не подтверждение неизвестной
глубины, диаметра или способа прокладки.

Тротуар и проезжая часть имеют разные категории. Радиус растения,
расстояние между растениями и отступ от препятствия — разные параметры.

## Полнота и ошибки

Восстановленная область, линейный остаток, пропуск и подтверждённое исключение
учитываются отдельно. Отверстия сохраняются. Контур отображения без известной
погрешности не объявляется точной расчётной геометрией.

Повреждённый или устаревший снимок нельзя использовать для положительного
ответа. Область поиска означает отсутствие выявленных запретов в принятом
наборе данных, а не полное обследование территории.
