# Локальное приложение

Desktop-приложение открывает Web-интерфейс, запускает локальный API и хранит
профиль текущего пользователя. Плагин AutoCAD передаёт проверяемый билет
захвата; повтор передачи не должен создавать дубликат проекта.

## Ответственность оболочки

- Одно окно и экземпляр runtime для профиля.
- Приём передачи, проверка готовности и открытие проекта.
- Защита несохранённых изменений при закрытии и переходах.
- Выбор компонентов и сохранение выходных файлов системным диалогом.
- Состояние ошибки и явный перезапуск API.

Локальный API защищён сеансом приложения. Секрет сеанса, произвольные URL
и команды не принимаются из билета. При перезапуске старые записи не
повторяются автоматически; новое поколение runtime получает новый сеанс.

Сбой интерфейса не считается успешным сохранением. При неизвестном результате
нужно восстановить состояние операции или квитанцию.
