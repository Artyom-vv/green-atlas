# Подготовка Windows и упаковка

Поставка 133 — один EXE для Windows x64: desktop host, локальный API,
скомпилированный Web, GUI-плагин 0.1.48 и Core worker 0.1.49.
AutoCAD, Blender и Botaniq/PBR устанавливаются отдельно.

## Установка

Установщик работает для обычного пользователя. Он размещает bundle в
`%APPDATA%\Autodesk\ApplicationPlugins\GreenAtlas.bundle`, создаёт ярлыки
и запись удаления. Для пользователя не нужны Python, Node.js или SDK.
Перед обновлением закройте Green Atlas и AutoCAD.

Профиль `%LOCALAPPDATA%\GreenAtlas` сохраняется при обновлении и удалении.
Заблокированный или изменённый программный комплект не заменяется принудительно.
При блокировке закройте удерживающий процесс и повторите действие.

## Проверяемость сборки

Manifest связывает версии компонентов, размеры и SHA файлов с исходным срезом.
Проверка manifest не заменяет запуск установленного приложения с AutoCAD
и Blender. Плагин и worker имеют собственные версии, отличные от номера Setup.

Установка, обновление, повторный запуск и удаление 133 проверены на Windows.
Границы CAD- и Blender-приёмки описаны отдельно.
