# Проверка и выпуск

## Назначение

Зафиксировать проверенное состояние проекта и выдать согласованный набор файлов с едиными идентификаторами.

## Проверка

Замечания пересчитываются при изменении плана. Пользователь переходит от замечания к объекту и исправляет его в том же рабочем пространстве. Hard errors блокируют final-выпуск; draft может быть создан с явными предупреждениями.

## Состав выпуска

- DXF с отдельными слоями посадок;
- CSV-ведомость;
- SVG-дендроплан;
- JSON-сцена;
- manifest;
- ZIP полного выпуска.

## Гарантии

- существующий export не пересчитывается при изменении проекта;
- версия проекта и артефакт фиксируются атомарно;
- конфликт конкурентного изменения не публикует недоступный результат;
- object ID сохраняются между связанными артефактами;
- release bundle может восстановить редактируемую ревизию при полной семантике.

## Ограничения

- final требует отсутствия hard errors и назначенных ревизий пород;
- старый или неполный пакет может открыться read-only;
- экспорт не подтверждает нормативное согласование проекта.

**Проверено:** release/export и integrity-контракты имеют тесты. **Реализовано, не проверено E2E:** выпуск из нового AutoCAD-native пользовательского маршрута. **План:** сквозная приёмка. **Историческое:** DXF export не доказывает, что первоначальная native extraction или слойная семантика были полными.
