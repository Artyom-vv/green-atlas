# Проверка и выпуск

## Проверить план

Проверка использует тот же подготовленный снимок и профиль правил, что посадка.
Она учитывает текущий горизонт роста, ревизии и сохранённые замечания исходника.
Откройте список проблем, выберите объект и исправьте конфликт либо явно
зафиксируйте предусмотренное решение.

## Выпустить результат

1. Сохраните план и проверьте замечания.
2. Выберите черновой или финальный выпуск.
3. Укажите применимость и статусы требуемых процедур.
4. Дождитесь создания и проверки файлов, сохраните комплект.

Пакет содержит доступные для выбранного выпуска чертёж, ведомости и сведения
о проверке. Для DWG требуется AutoCAD: он добавляет посадки в копию архива,
повторно открывает результат и проверяет состав. Исходник не перезаписывается.
Пакет публикуется после согласованной проверки, а не по одному коду выхода.

Черновик сохраняет замечания. Финальный выпуск требует прохождения
предусмотренных проверок плана и процедурных статусов. Заполненный статус
не означает получения разрешения государственным органом.

![Проверка и выпуск](../assets/diagrams/03-review-and-save.svg)

Если результат операции неизвестен, сначала восстановите его состояние;
не запускайте повторную запись вслепую.
