# Работа с CAD и DXF

## Вход и результат

Вход: открытый DWG/DXF в полном AutoCAD 2027. Плагин передаёт захват,
доступные XREF, отображение и каталог объектов. AutoCAD подготавливает
расчётные области и линии; Green Atlas сохраняет снимок и замечания.

## Правила

- Исходные DWG и XREF не перезаписываются; архив и выпуск создаются отдельно.
- Идентичность объекта включает источник, handle и цепочку экземпляров.
- Исходный слой и слой экземпляра учитываются раздельно.
- Подписи сохраняют происхождение; соседний текст не доказывает параметр трубы.
- Хеши, версии компонентов, размеры и конечность координат проверяются до приёма.
- Непрочитанные объекты, недоступные XREF и неизвестные роли имеют разные причины.
- Линейный остаток не заменяется выдуманной площадью или прямоугольником.

После подготовки посадки проверяются локально по одному снимку. Новые файлы
не загружаются через DXF/ZIP в браузере. Старые читатели и сохранённые проекты
остаются только совместимостью.

## Ошибки и повтор

Проверьте доступность XREF, совместимость worker, назначения и выбранную границу.
При неполных данных приложение сохраняет замечания. Явная работа по доступной
геометрии не означает полноту участка или безопасность всех мест.

В 133 завершённое собственное Windows-задание Core может быть очищено только
после проверки результата, затем результат проверяется повторно. Код выхода 0
сам по себе не подтверждает успешную подготовку.
