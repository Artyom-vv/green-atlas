# macOS: границы документации

Кодовая база содержит оболочку macOS, сборщик приложения и установщика.
Текущая инструкция поставки относится к **Windows 0.1.133**.
Квалифицированный установщик Mac 133 в этом комплекте не заявлен.

Общие API, правила и проектные данные не образуют отдельный алгоритм для Mac.
Платформенные различия — запуск AutoCAD, процессный надзор, WebView,
выбор файлов, профиль и упаковка.

Сборка и проверка Mac выполняются в отдельном профиле. Рабочая установка,
исходные DWG и пользовательская база не используются как временные данные.
Успех теста Mac не подтверждает Windows и наоборот.

Прежние версии, инструкции и результаты Mac находятся в
[архиве документации](https://github.com/Artyom-vv/green-atlas/tree/main/docs/archive/pre-133).
