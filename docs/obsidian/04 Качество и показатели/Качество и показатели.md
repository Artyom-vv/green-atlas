# Качество и показатели

## Основание версии 133

Предварительный выпуск от 20 октября 2026 года. Исходный срез:
`5539e638f8a60241c95f5dcc5e6c2040a23f5a14`.
Проверяемый файл: `GreenAtlas-0.1.133-Windows-x64-Setup-2.exe`.
[Примечания и файлы выпуска](https://github.com/Artyom-vv/green-atlas/releases/tag/v0.1.133-windows).

| Проверка | Подтверждённый результат |
|---|---|
| Установка обычным пользователем | Завершение мастера, запуск, компоненты, повторный запуск |
| Обновление 132 → 133 | Синтетический подготовленный проект, Undo/Redo и повторное открытие |
| Заблокированный файл установки | Ошибка Win32 32, сохранность данных, успешный повтор после освобождения |
| Удаление | Пользовательские данные сохранены |
| CAD Core, 8 DWG/XREF | Исходный runtime 133: подготовка завершена за 140,69 с, собственное дерево процессов очищено, результат повторно проверен |
| Упакованный runtime 133 | Принял подготовленный результат и повторно открыл его без пересчёта CAD |
| План и участки | Посадка и два участка, сохранение, Undo/Redo, перезапуск; предупреждение о неполной геометрии сохранено |

Сценарий плана выполнялся с явной политикой `available_data`;
`SOURCE_GEOMETRY_PARTIAL` не снималось. CAD-измерение — один конкретный прогон,
не гарантированное время для любого чертежа. Проверка внутренних признаков
очистки выполнена в исходном runtime, а не через установленное окно.

## Что не подтверждено этим выпуском

- Полный CAD-путь через окно установленного desktop-приложения.
- Реальный рендер Blender на Windows.
- Полный сценарий отдельной Windows-учётной записи с кириллическим именем.
- Полнота произвольных XREF и соответствие всем действующим нормативам.

## Приёмка нового комплекта

Проверяйте установку, захват CAD, назначения, подготовку, посадку, сохранение,
повторное открытие и CAD-выпуск. Отдельно — отмену, потерянный ответ,
устаревший предпросмотр, пропуски XREF, рост, 3D и рендер.
Записывайте версию, конфигурацию ПК, данные, единицы и границы измерения.

История тестов и старых сборок находится в
[отдельном архиве](https://github.com/Artyom-vv/green-atlas/tree/main/docs/archive/pre-133).
Дата правки этой страницы не является датой нового продуктового прогона.
