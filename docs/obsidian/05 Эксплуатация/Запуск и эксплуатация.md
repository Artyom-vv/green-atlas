# Запуск и эксплуатация

Новую подоснову передавайте из AutoCAD командой `GAOPEN`.
Сохранённые проекты доступны в библиотеке Green Atlas.
[[05 Эксплуатация/Установка и проверка Windows|Установка и требования]].

## Где хранятся данные Windows

| Путь | Содержимое |
|---|---|
| `%APPDATA%\Autodesk\ApplicationPlugins\GreenAtlas.bundle` | Программный комплект |
| `%LOCALAPPDATA%\GreenAtlas` | Профиль: Workspace, Transfers, WebView2 и Logs |
| `%LOCALAPPDATA%\Green Atlas\external-tools.json` | Настройки AutoCAD, Blender, Botaniq и PBR |
| `%LOCALAPPDATA%\Green Atlas\render-resources.json` | Совместимая отдельная настройка ресурсов |

`GreenAtlas` и `Green Atlas` — разные каталоги. Предпочтительный способ
менять пути — кнопка «Компоненты», а не ручное редактирование JSON.

## Сохранность

Обновление и удаление программы сохраняют профиль. Для резервной копии
используйте предусмотренный сценарий копирования профиля с архивами CAD
и связанными коллекциями. Одна SQLite-база не содержит всех данных проекта.
Не перезаписывайте исходные DWG и не очищайте Workspace для исправления ошибки.

## Если операция не завершилась

- Проверьте её состояние и замечания; неизвестный результат записи не повторяйте вслепую.
- Для CAD проверьте AutoCAD, worker, XREF и назначение слоёв.
- Для 3D проверьте Blender и локальные ресурсы.
- При блокировке обновления закройте процессы, использующие программный комплект.
- Для обращения приложите версию, шаги и относящиеся к сбою записи из Logs.

Не публикуйте рабочие проекты, ключи и секреты сеанса вместе с журналами.
