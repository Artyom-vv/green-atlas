## Зафиксированные решения

| Решение | Причина | Последствие |
|---|---|---|
| AutoCAD — source of truth для native geometry | Нужны авторитетные REGION/HATCH/XREF и transforms | Нет fallback parser в native production-flow |
| DXF — обменный и выпускной формат | Переносимый пакет результата | Не является источником native production geometry |
| Исходник хранится отдельно | Возможность аудита и восстановления | Производные данные можно пересчитать |
| Preview отделён от apply | Контроль пользователя | Требуются digest и версии |
| Правила живут на backend | Один источник истины | UI не рассчитывает нормы |
| Неизвестное не считается безопасным | Исключение ложных выводов | Возможен статус «нужно уточнение» |
| Coverage важнее ложной полноты | Остаточные instances должны быть видимы | Допускается работа по available-data scope |
| Агент использует обычные сценарии | Не обходить предметные гарантии | Автономность намеренно ограничена |
