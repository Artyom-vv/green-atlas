# Пример работы — Кустанайская

## Цель

Создать новый проект по комплекту Кустанайской улицы, выбрать участок
и сохранить вариант озеленения. Сценарий использует общие функции сервиса;
отдельного алгоритма для этой улицы нет.

## Исходные данные

- Архив `submission/prototype/Kustanayskaya-CAD.zip` с генпланом и девятью
  связанными DWG. Файлы находятся в папке `Кустанайская`.
- Доступные внешние ссылки этого комплекта.
- Совместимая установка AutoCAD и Green Atlas.
- Для примера: спирея японская, размер standard, запрос 15 кустов.

Не требуется существующий идентификатор проекта или заранее сохранённый
участок. Повтор создаётся в новом проекте, прежние посадки остаются нетронутыми.

Генплан и девять связанных DWG уже опубликованы в общем CAD-архиве.
Распаковать его нужно целиком, сохранив относительные пути подоснов.
Для Mac опубликован установщик 0.1.45, для Windows — отдельный 0.1.42.
Предложения Luna для неизменённого исходника включены в оба пакета,
поэтому ключ OpenAI и Codex для этого демонстрационного сценария не нужны.
В исходном комплекте отсутствует один XREF; он остаётся адресным замечанием.

## Последовательность

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть генплан в AutoCAD и проверить XREF | Понятно, какие подосновы доступны |
| 2 | Запустить Green Atlas через плагин | Создан локальный проект |
| 3 | Проверить назначения слоёв | Физические объекты учитываются по смыслу |
| 4 | Выбрать расчётную границу | Территория проекта определена |
| 5 | Рассмотреть замечания и подготовить карту | Сохранена расчётная геометрия |
| 6 | Нарисовать новый рабочий участок | Задана область задачи |
| 7 | Выбрать растение, количество и размещение | Создан запрос подбора |
| 8 | Рассмотреть вариант и причины замечаний | Понятно, какие места найдены |
| 9 | Подтвердить посадки | План сохранён |
| 10 | Вернуться к проекту через список | Состав и координаты посадок сохранены |
| 11 | Создать CAD-выпуск | Получен отдельный комплект с DWG и доступными подосновами |
| 12 | Распаковать ZIP и открыть planting-plan.dwg в AutoCAD | Посадки присутствуют на новых слоях, XREF загружаются рядом |

Нужное количество не гарантируется для произвольного нарисованного участка.
При частичном подборе следует проверить причину завершения поиска.

## Что проверить в исходнике

| Ситуация | Правильная трактовка |
|---|---|
| Несколько границ | Выбрать границу работ, а не любую замкнутую линию |
| Название покрытия содержит замену одного материала другим | Проверить, какой объект обозначен фактически |
| Недоступная внешняя ссылка | Зафиксировать пропуск, не считать его свободным пространством |
| HATCH без области | Рассмотреть замечание к геометрии отдельно от назначения слоя |
| Линия без площади | Проверить линейный учёт и доступные предложения восстановления |

Исключать все неясные слои ради продолжения расчёта нельзя.

## Критерии завершения

- Расчётная граница и назначения сохранены.
- Неполнота и рабочие допущения видимы.
- Контрольные точки внутри известных здания и проезда не принимаются.
- Вариант сохраняется без потери существующих данных.
- Повторное открытие показывает тот же план.

Для CAD-выпуска нужен совместимый комплект приложения и плагина, а также архив
того же захвата. Сборка 0.1.43 не принимает собственный снимок: в API была
пропущена новая версия плагина. Не используйте её для нового захвата.
Черновик с неполными проверками сохраняет замечания.

## Размещение посадок

В интерфейсе пользователь выбирает вид, количество и параметры размещения на
сохранённом участке. Сервис предлагает подходящие позиции и показывает
замечания до сохранения. Подтверждение выполняется в том же экране.
Автоматический выбор вида временно скрыт. На отдельной копии проекта ранее
проверены 8 из 8 кустов у здания и повторное открытие после сохранения.
Состав архива и порядок проверки описаны в `submission/prototype/README.md`.

Подбор породы пока не учитывает индивидуальный тип соседнего объекта.
На рабочем Mac пользователь подтвердил весь путь до повторного открытия
выпуска в AutoCAD. Windows-пакет отдельно прошёл сценарий на стенде.
Установка на чистом компьютере для обеих платформ пока не принята;
полный повторный выпуск на Mac 0.1.45 не заявляется как проверенный.
