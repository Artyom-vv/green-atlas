# Известные ограничения

| Ситуация | Что учитывать |
|---|---|
| Недоступный XREF или непрочитанный объект | Пропуск остаётся замечанием; это не свободное место |
| Работа по доступной геометрии | Требует явного решения; не подтверждает полноту исходника |
| Неизвестный параметр сети | Допущение обозначается отдельно от нормативного значения |
| Изменён горизонт роста | Ранее размещённые растения могут получить новые конфликты |
| Нулевой промежуточный результат поиска | Проверьте прогресс и причину остановки, а не только число посадок |
| Неизвестный результат записи | Восстановите состояние операции или квитанцию перед повтором |
| Нет высоты OSM | Представление использует обозначенное приближение |
| Нет точной модели растения | Возможна модель-замена; это не биологическое подтверждение |
| Файл установки занят | Закройте удерживающий процесс и повторите Setup |
| Финальный выпуск | Не заменяет разрешения и согласования |

Для Windows 133 полный установленный CAD-сценарий и реальный Blender-рендер
не подтверждены сквозной приёмкой этого выпуска.
