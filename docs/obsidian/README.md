# Документация Green Atlas

Green Atlas — рабочее пространство для проверяемого проектирования озеленения поверх CAD-комплекта. Канонический production-поток извлекает расчётную геометрию AutoCAD/ObjectARX, фиксирует её provenance и coverage, допускает снимок, а затем отдельно проводит пользовательскую классификацию слоёв, расчёт, редактирование и выпуск.

## Статус документации

Факты сверены с кодом, контрактами, тестами и native receipt от 22 сентября 2026 года. Геометрический AutoCAD-поток имеет отдельную живую проверку; классификация слоёв, расчёт ограничений и сквозной пользовательский flow не должны выводиться из неё автоматически.
