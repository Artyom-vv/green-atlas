# Документация Green Atlas

Green Atlas помогает проектировщику размещать озеленение по CAD-подоснове.
AutoCAD читает чертёж и подготавливает геометрию. Green Atlas определяет
ограничения, предлагает места и сохраняет выбранные посадки.

## Область документации

Документация описывает путь «AutoCAD → локальный проект → подготовленная
геометрия → посадки». Совместимость со старыми проектами не является вторым
способом подготовки нового чертежа.

Страницы и схемы входят в один комплект. Его можно открыть как хранилище
Obsidian без доступа к переписке, исходному репозиторию и внешним изображениям.
Пути к коду приведены как справочные указатели для разработчика, а не как
условие понимания текста.
