# Назначение продукта

Green Atlas помогает проектировщику размещать деревья и кустарники по
CAD-подоснове, проверять ограничения и выпускать отдельный чертёж с ведомостями.

Основной путь: **открытый AutoCAD → подготовка → участок и растения →
предпросмотр → применение и сохранение → выпуск**.

У каждого действия видимый результат: подготовленная карта, предложенный
вариант, сохранённый план или файл. Расчётные данные, допущения и замечания
показываются раздельно. Подтверждённые решения не заменяются догадкой модели.
