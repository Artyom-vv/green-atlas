# Что хранится в репозитории

В Git входят код, тесты, небольшие проверочные данные, архитектурные контракты,
модульная документация, база знаний и дизайн-система.

Локально остаются `HANDOFF.md`, `output`, `artifacts`, аудиты, дневники
реализации, прототипы, исследовательские выгрузки и исходные вложения.
Эти каталоги перечислены в `.gitignore`. Не добавляйте их через `git add -f`.
Сюда также относятся `design-qa.md`, дизайн-исследования и журнал наблюдений
`EVIDENCE.jsonl`. Правила оформления сохраняются в `docs/design-knowledge`,
иконки — в `docs/design-system/assets`.
Страницы документации и SVG-схемы хранятся в `docs/obsidian`; скачиваемый архив
собирается командой `python3 scripts/docs/package_vault.py`.

## После очистки истории

История всех опубликованных веток переписана. Сохраните свои незакоммиченные
изменения отдельно и заново клонируйте репозиторий. Переносите только нужные
правки кода, без старого каталога `.git` и исключённых материалов.

Не сливайте старые ветки и не отправляйте старые теги: это вернёт удалённую
историю. Исторические хеши из локальных заметок могут больше не разрешаться.
Рабочие DWG, проекты и локальные отчёты не относятся к Git и сохраняются отдельно.

## Локальные сборки и проверки

После проверки сохраняем текущий установочный комплект, предыдущий комплект
для отката и компактные квитанции с составом и результатами. Промежуточные
сборки, копии QA-профилей и дубли производных CAD-снимков удаляем после
завершения соответствующей проверки. Не переносим их в новые резервные
архивы вместо удаления. Исходные чертежи, рабочие базы, распакованный датасет
и материалы конвейера рендеров сохраняем отдельно от этих временных данных.

В `submission` находятся материалы сдачи: презентации, выбранные скриншоты,
метаданные установщика и проверенный `prototype/Kustanayskaya-CAD.zip` с десятью
CAD-файлами. Установщик 0.1.133 опубликован отдельным GitHub Release; видео
и Botaniq/PBR доступны по ссылке на материалы. Библиотеки, рабочие проекты,
полные датасеты и ключи не добавляются в Git.

Архив `docs/archive/pre-133` содержит только ранее опубликованную документацию
и SVG без изменений, с контрольными суммами. Это не разрешение публиковать
локальные аудиты, журналы или приватные материалы. Старые инструкции внутри
архива не определяют поведение текущего выпуска.

По явному решению владельца Mac-выпуск может включать ключ DaData по умолчанию
и отдельный отзываемый доступ выпуска к AI relay. Эти значения передаются сборщику
из приватных файлов, не входят в Git и не публикуются автоматически вместе с
исходниками. Они извлекаются из установщика и не считаются защищёнными секретами
клиента. Ключ OpenAI, серверный прокси, персональный relay-токен, рабочие базы
и журнал расходов в пакет не включаются. Бюджет relay остаётся серверным и не
обнуляется при установке. Подробности: [доступ AI в выпуске](<obsidian/03 Модули/Доступ AI в выпуске.md>).
