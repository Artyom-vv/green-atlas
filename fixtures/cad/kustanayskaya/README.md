# Кустанайская улица — следующий реальный тестовый комплект

Выбрана пользователю вместо 3-й Парковой 16 сентября 2026 года. В комплекте
есть отдельные файлы топографии, сетей, границ, генплана и дендроизысканий.
Выбор основан на составе официального архива, **не на готовом результате импорта**.

В Git передаются **только manifest, инструкции и скрипт**, без CAD-бинарников:
датасет уже есть на ПК пользователя. Manifest описывает все **10 DWG** из папки
`18. Кустанайская улица/Исходные данные` основного ZIP, без служебных PaxHeader.
Общий размер — 32 024 593 байта. На Mac они извлечены без преобразования и
проверены; локальная `source/` исключена из Git. Это не весь датасет и не
доказанно замкнутый граф CAD-зависимостей.

**Это сырьё для подготовки тестового DXF, а не новый DWG-вход сервиса.**
Конвертация выполняется заранее вне продукта. Вход/выход продукта — DXF;
поддерживается полный комплект нескольких DXF в одном проекте.

## Точки входа

Пути ниже относительно `source/`:

- `05_10004141_Генплан_Кустанайская ул. - Standard/05_10004141_Генплан.dwg` — кандидат на корневой чертёж.
- В его `00.3_Ссылки/`: `00.1_10004141_Топография.dwg`, `00.2_10004141_Сети.dwg`,
  `00.3_10004141_Граниицы.dwg`, `01_10004141_Границы работ.dwg` и ещё три CAD-файла.
- `000749-2026_Кустанайская улица/ИП_Кустанайская улица/` — два CAD-файла изысканий.

Файл с названием `03_10004141_Проектные решения.dwg` не следует автоматически
считать существующими ограничениями. При обследовании установить роли слоёв,
проектные/существующие объекты и связи; не подмешивать готовый план вместо
результата нашего алгоритма.

## Проверка имеющегося датасета на ПК

Python 3.10+ и стандартная библиотека; CAD SDK для сверки SHA не нужен:

```text
python scripts/cad-lab/prepare_kustanayskaya_fixture.py --verify-source "PATH/18. Кустанайская улица/Исходные данные"
```

В Windows сначала выполнить `scripts/windows-env.ps1`, как требует AGENTS.md.
Ожидается `files_verified: 10`, `bytes: 32024593`. [manifest.json](manifest.json)
содержит точные пути в архиве, размеры и SHA256 каждого файла.

Для воспроизведения извлечения в **новую** папку:

```text
python scripts/cad-lab/prepare_kustanayskaya_fixture.py --archive "PATH/Пилотный проект 20 улиц.zip" --destination ".runtime/kustanayskaya-reextract"
```

После извлечения использовать `--verify .runtime/kustanayskaya-reextract`.
Существующие файлы не перезаписываются. Особенность исходного архива: часть имён
закодирована CP866, часть уже предоставляется ZIP-библиотекой в Unicode.
При извлечении стандартной системной утилитой могут появляться нечитаемые имена.

## Не передано и не проверено

- Не копировались шрифты, PDF, ведомости и остальные не-CAD-файлы из исходной
  папки; их точный список сохранён в `omitted_non_cad_source_entries` manifest.
  Если они требуются для вида/содержательной сверки, взять их из полного датасета.
- Не копировались соседние архивы и итоговый `ГП_Кустанайская (1).pdf` (45,7 МБ)
  в корне папки улицы. PDF — возможный визуальный эталон, не расчётная геометрия.
- DWG ещё не преобразованы в DXF; координаты, ссылки, типы сетей и сложные тела
  ещё не исследованы. Нельзя объявлять этот комплект нормативно готовым.

Повторно передавать архив ~11,46 ГБ не нужно: он уже есть на ПК. Для первого
шага используется эта папка улицы, а не распаковка/конвертация всех 20 улиц.
Остальной архив понадобится, если обнаружатся дополнительные зависимости.
Парковая остаётся контрольным примером прежних ошибок, но не основным сценарием.
