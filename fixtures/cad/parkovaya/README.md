# Официальный исходный DWG: 3-я Парковая

`parkovaya-apot-original.dwg` — побайтная копия основного чертежа
`01-25-ДВ-ВАО-10001759-АПОТ.dwg` из официального датасета ЛЦТ.
Имя файла упрощено для воспроизводимости CLI на Windows; содержимое не менялось.
Добавлен в репозиторий по прямому запросу пользователя для исследования на ноутбуке.

- Размер: **26 293 408 байт**.
- SHA256: `64a6628eb402566b1010657717f71b9e7c3a00e07be7efc381750475b39b1d47`.
- Источник и относительный путь: [manifest.json](manifest.json).
- Инструкции продолжения: [handoff для ноутбука](../../../docs/implementation/2026-09-16-laptop-handoff.md).

Это оригинальный DWG, не DXF и не производная сборка. В нём воспроизводятся
ошибки MATERIAL, ACDSDATA, четырёх REGION и текстового экспорта, описанные
в отчёте. **Внешние DWG-ссылки не включены:** с одним файлом нельзя подтвердить
полноту всей улицы. Геоподоснова, уже встроенная в корень, сохраняется.

Хранится обычным Git blob; Git LFS и отдельная загрузка не требуются.
Не сохраняйте результат CAD-редактора поверх этого файла. Все производные
файлы направляйте в `.runtime/`, которая исключена из Git.
