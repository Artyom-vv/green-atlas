# Нагрузочный чертёж Китай-города

`kitay-gorod.osm.json` — зафиксированный снимок OpenStreetMap для центра Москвы в границах `55.7460, 37.6100, 55.7585, 37.6370`. Он охватывает Китай-город, прилегающую часть Кремля, Зарядье и плотную улично-квартальную среду вокруг них.

Исходные данные получены 2 сентября 2026 года через официальный Overpass API; зафиксированная версия базы OSM — `2026-09-02T08:55:24Z`. Авторство: © OpenStreetMap contributors. Лицензия: Open Database License, https://www.openstreetmap.org/copyright.

Повторное создание DXF:

```bash
apps/api/.venv/bin/python fixtures/large-map/kitay-gorod/generate_kitay_gorod_dxf.py
```

В отличие от фикстуры ВДНХ этот чертёж проверяет плотную историческую среду. В DXF раздельно сохраняются здания, основные и местные дороги, пешеходные пути, железнодорожная геометрия, вода, существующее озеленение и отдельные деревья, ограждения, технические сооружения и справочные контуры.

## Пространственная версия

`generate_kitay_gorod_3d_dxf.py` создаёт отдельный `kitay-gorod-3d.dxf`, не
подменяя исходный плоский fixture. Горизонтальная геометрия и геопривязка
остаются из зафиксированного OSM-снимка. Поверхность рельефа берётся из
Copernicus DEM GLO-90 через Open-Meteo и кэшируется в
`kitay-gorod.copernicus-glo90.json`; обязательная атрибуция — Copernicus
Programme и Open-Meteo. Это оценочная DSM с шагом около 90 м, не инженерная
топосъёмка: официально заявлены абсолютная вертикальная точность < 4 м (90% LE)
и горизонтальная < 6 м (90% CE). DXF хранит явный статус `estimated`, а точное
лицензионное уведомление и [условия Copernicus DEM](https://dataspace.copernicus.eu/sites/default/files/media/files/2025-06/copernicus_contributing_mission_data_access_v2_cop_dem_licenses.pdf)
зафиксированы в кэше. Абсолютная минимальная отметка DEM записана в кэш, а Z
в DXF нормализован относительно неё, чтобы сцена сохраняла численную точность.

Здания с OSM `height` находятся в слое
`GREEN_ATLAS_BUILDING_OSM_HEIGHT`. Высота по `building:levels` (3 м на этаж,
плюс явный `roof:height`) лежит отдельно в
`GREEN_ATLAS_BUILDING_OSM_LEVELS` и должна показываться интерфейсом как оценка,
а не геодезически подтверждённая величина. Контуры без этих тегов не получают
выдуманную экструзию.

```bash
apps/api/.venv/bin/python fixtures/large-map/kitay-gorod/generate_kitay_gorod_3d_dxf.py --refresh-dem
```

Фикстура нужна для проверки импорта, выбора зоны, hit-testing перекрывающихся контуров, нормативных отступов, запрета посадок поверх существующего озеленения и производительности массового предпросмотра. Это открытая картографическая подложка, а не инженерно-топографический план: отсутствие объекта в OSM нельзя трактовать как подтверждение возможности посадки.
