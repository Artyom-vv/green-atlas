# Проверка документации

Комплект `docs/obsidian` содержит самостоятельные страницы и локальные SVG.
Разовые инженерные журналы и временные данные в архив не включаются.

Из корня репозитория:

```sh
python3 scripts/docs/check_vault.py
python3 scripts/docs/package_vault.py
python3 -m unittest discover -s scripts/docs -p 'test_*.py'
```

В Windows сначала применяется `scripts/windows-env.ps1` в той же сессии.

Проверяются внутренние ссылки, локальные изображения, отсутствие привязок
к конкретной машине/сессии, корректность SVG и состав архива.
Архив распаковывается в отдельный временный каталог и проверяется повторно.
Контрольные суммы всех страниц и изображений находятся в MANIFEST.sha256.

Результат: `output/documentation/Green-Atlas-documentation.zip`.
Каталог Obsidian внутри архива открывается без соседних файлов репозитория.
Схемы вставлены в пользовательский путь и соответствующие модульные страницы;
один SVG переиспользуется несколькими страницами.

Проверка документации не запускает AutoCAD и не подтверждает исправление
продуктовых дефектов. Места кода и результаты испытаний указаны отдельно
в разделах технических оснований и качества.
