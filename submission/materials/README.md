# Дополнительные материалы Green Atlas

## Видеодемонстрации прототипа

В [папке на Яндекс Диске](https://disk.yandex.ru/d/vEO0vpO6jMGhDQ)
размещены два видеоролика:

- Демонстрация Green Atlas на Windows
- Демонстрация Green Atlas на macOS

Откройте папку по ссылке, чтобы посмотреть или скачать записи.
Установочные комплекты и инструкции находятся в
[разделе прототипа](../prototype/README.md).
