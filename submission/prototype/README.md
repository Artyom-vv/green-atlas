# Прототип Green Atlas: Кустанайская улица

Проверочный комплект для macOS 14 и новее, Apple Silicon и полного AutoCAD 2027.
Сборка на macOS 14/15 совместима по [требованиям AutoCAD 2027](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/System-requirements-for-AutoCAD-2027-including-Specialized-Toolsets.html) и минимальной
версии бинарников, но пока испытана вручную только на macOS 26. В этой папке
лежат приложение с плагином и отдельный архив исходных CAD-файлов улицы.
Проект Green Atlas заранее не создан: его создаёт пользователь при открытии
чертежа. Отдельный Windows-комплект описан ниже; он не заменяет Mac-сборку.

| Платформа | Установочный архив |
|---|---|
| macOS 14 и новее, Apple Silicon | [GreenAtlas-AutoCAD-Mac-0.1.45.zip](GreenAtlas-AutoCAD-Mac-0.1.45.zip) |
| Windows 11 x64, AutoCAD 2027 | [GreenAtlas-AutoCAD-Windows-0.1.42.zip](GreenAtlas-AutoCAD-Windows-0.1.42.zip) |

CAD-комплект [Kustanayskaya-CAD.zip](Kustanayskaya-CAD.zip) общий для обеих платформ.
Номера Mac- и Windows-сборок независимы: Windows-архив не содержит последние
Mac-правки 0.1.45 и не заявляется как полностью идентичная версия.

Установщик не устанавливает AutoCAD и не требует от проверяющего Python,
Node.js, SDK, Codex или ключ OpenAI. Плагин, локальное приложение, расчётный
движок и интерфейс входят в один пакет. Проекты хранятся локально в папке
`~/Library/Application Support/Green Atlas/Workspace`.

## Запуск с нуля на Mac

1. Скачайте репозиторий и распакуйте [Kustanayskaya-CAD.zip](Kustanayskaya-CAD.zip)
   в любую папку. Внутри находится папка `Кустанайская` с генпланом и девятью
   связанными DWG. Не перемещайте отдельные файлы: относительные пути внешних
   ссылок должны сохраниться.
2. Распакуйте [GreenAtlas-AutoCAD-Mac-0.1.45.zip](GreenAtlas-AutoCAD-Mac-0.1.45.zip).
   Закройте AutoCAD и Green Atlas, затем откройте `Green Atlas Installer.app`.
   Он устанавливает приложение и плагин для текущего пользователя, не меняя
   исходные чертежи.
3. В AutoCAD откройте
   `Кустанайская/05_10004141_Генплан_Кустанайская ул. - Standard/05_10004141_Генплан.dwg`.
   Откройте лист `1`: в нём должен быть виден весь чертёж, а не только контур.
   Проверьте состояние XREF и выполните команду `GAOPEN`. Green Atlas создаст
   локальный проект из отдельной копии чертежа.
4. В Green Atlas проверьте предложения Luna. Для DWG из этого архива
   сохранены только предложения модели, не подтверждения из другого проекта:
   ключ OpenAI для просмотра предложений не нужен. Однозначные роли сервис
   принимает автоматически; оставшиеся показываются для проверки.
   Выберите границу территории и нажмите «Подготовить карту».
   Замечания об отсутствующих объектах или XREF
   остаются замечаниями, а не автоматически считаются свободной площадью.
5. На карте создайте и сохраните рабочий участок. Откройте размещение посадок,
   выберите вид растений, количество и параметры размещения.
6. Нажмите «Найти места». Приложение покажет найденное количество и вид.
   Это предпросмотр: план ещё не меняется. Нажмите «Добавить», чтобы сохранить
   предложение, затем откройте проект повторно и проверьте посадки.
7. При необходимости создайте отдельный CAD-выпуск из интерфейса. Он не
   перезаписывает исходный DWG.

## Если возникла проблема

| Ситуация | Что делать |
|---|---|
| На Mac установлена macOS 13 или процессор Intel | Эта Mac-сборка не подходит. Нужен Mac с Apple Silicon и macOS 14 или новее; установка не должна менять файлы. |
| AutoCAD отсутствует либо установлен AutoCAD LT | Установите и активируйте полный AutoCAD 2027 для Mac. Установщик Green Atlas его не заменяет. |
| macOS не открывает скачанный установщик | Сначала проверьте, что архив получен из этого репозитория и совпадает с SHA-256 ниже. После попытки запуска откройте «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть» по [инструкции Apple](https://support.apple.com/ru-ru/102445). Не отключайте защиту macOS целиком и не снимайте карантин командой для всей папки. Если политика рабочего Mac не разрешает исключение, нужен подписанный и заверенный Apple дистрибутив. |
| Установщик просит закрыть приложения | Сохраните работу и закройте AutoCAD и Green Atlas, затем повторите установку. Старый установленный пакет при обновлении сохраняется как резервная копия. |
| Команда Green Atlas не появилась в AutoCAD | Полностью завершите и вновь запустите AutoCAD после установки. Убедитесь, что стоит именно полный AutoCAD 2027. Если macOS отдельно блокирует плагин, не обходите защиту всей системы; сообщите разработчикам, какая программа заблокирована. |
| После команды появляется «Не удалось принять снимок» | Проверьте версию установленного пакета: сборка 0.1.43 содержала несовместимые плагин и локальный API. Установите комплект 0.1.45 целиком, закройте и повторно запустите AutoCAD и Green Atlas, затем вызовите команду заново. Подготовленный ранее файл передачи не нужно открывать вручную. |
| В `Model` виден только контур | Переключитесь на лист `1`: там должен быть виден полный чертёж. Сам по себе вид `Model` не доказывает потери данных. |
| Лист `1` пуст | Откройте `Reference Manager`: доступные DWG должны находиться в соседнем каталоге `00.3_Ссылки` и быть загружены. Если XREF загружены, проверьте, не выключены ли их слои и не включена ли изоляция объектов. Если они на диске, но не загружены, обновите внешние ссылки. При сомнении закройте чертёж без сохранения изменений и вновь откройте генплан из полной распакованной папки. Если macOS запрашивает доступ AutoCAD к папке, разрешите его для этой папки. Не продолжайте подготовку карты с пустым видом. Отсутствие одного исходного `I7 чб` само по себе не объясняет пустой лист. |
| Видно предупреждение об XREF | Проверьте сохранность структуры архива. В конкурсном исходнике один XREF отсутствует; это замечание к предоставленному CAD, а не ошибка установки. Не отмечайте неполные данные как подтверждённые. |
| Luna не распознаёт новый или изменённый DWG | Встроенные предложения относятся только к неизменённому исходнику Кустанайской и точному составу слоёв. Для другого чертежа нужен отдельно выданный доступ к серверу распознавания или локальная настройка API; личный ключ в архив не включён. |
| CAD-выпуск сообщает, что AutoCAD не найден | Проверьте полную установку AutoCAD 2027. Green Atlas ищет стандартные каталоги и зарегистрированное приложение; для нестандартного расположения можно передать путь к `.app` через `GREEN_ATLAS_AUTOCAD_ROOT` при запуске приложения. |
| На диске мало места | Освободите место для рабочей копии CAD, локальной базы и отдельного результата выпуска. Исходный DWG не перезаписывается. Не удаляйте вручную рабочую базу или каталог `.cad-archives`. |

CAD-выпуск в этой сборке запускает нативный компонент AutoCAD на Apple Silicon;
отдельная установка Rosetta для Green Atlas не требуется. Если AutoCAD сам
показывает запрос на свой дополнительный компонент, следуйте инструкции Autodesk.

Скрипт `scripts/demo/prepare_kustanayskaya.py` нужен только разработчику для
сверки контрольных сумм и создания рабочей копии из официального датасета.
Он не объединяет здания, не замыкает контуры и не изменяет геометрию. Для
воспроизведения архива запускать его не нужно.

## Состав исходного архива

Архив содержит десять исходных DWG Кустанайской с проверенными SHA-256,
включая основной генплан и связанные CAD-подосновы. Генерированные ранее
снимки Green Atlas, шрифты и сопроводительные PDF в архив не включены.
Это комплект CAD для проверки приложения, а не полный официальный датасет.
SHA-256 архива: `26c8716251215a9dbc36927c35657e54abfdc75995a58cc92aab8d2bf8864798`.

## Статус проверки

29 сентября пользователь прошёл на Mac путь от открытия исходной Кустанайской
в AutoCAD через правки назначений слоёв и посадки до скачивания полного
чернового выпуска. Полученный DWG с подосновами он повторно открыл в AutoCAD
и подтвердил, что комплект работает. Это ручная проверка на рабочем Mac, а не
приёмка установки на чистом компьютере организаторов или Windows.

В отдельных проверках на новом проекте распознаны 124 слоя, подготовлена
карта и сохранены посадки. Наличие готовых предложений для неизменённого DWG
не означает, что все назначения слоёв подтверждены автоматически. Для другой
улицы живое распознавание Luna требует отдельной настройки доступа к API.
Выпуск остаётся черновым: замечания по исходным данным и сетям сохраняются
в пакете, а повторное открытие DWG не является нормативным согласованием.
Автоматический выбор вида временно скрыт в интерфейсе. Он не служит резервным
способом обхода ограничений: оба сценария используют одну область поиска.
Предложение не сохраняется без нажатия «Добавить».

Mac-сборка подписана тестово и не заверена Apple. На другом Mac защита системы
может остановить запуск. Для обычной публичной установки без ручного исключения
нужны Developer ID, нотариальное заверение и проверка на чистом компьютере.

Установщик дополнительно проверен на пути с символической ссылкой к родительской
папке и через штатную команду установки на Mac. Запуск из Finder на другом
чистом компьютере пока не подтверждён.

В 0.1.45 отмена подготовки передаётся ожидающему запросу AutoCAD, включая
ожидание блокировки. Каталог областей больше не подготавливает измерение
расстояний для всей улицы заранее. В сравнительном проверочном запуске
совпали все 32 519 областей, их площади, контуры и замечания с 0.1.44.
Пакет установлен на рабочем Mac, захват через меню AutoCAD проверен.
Полный повторный выпуск на 0.1.45 и установка на чистом Mac пока не проверены.

SHA-256 Mac-архива: `dc3f9c59e22b86eaed6c483ee3f646650d3e524810a75322b4766f06e46bc557`.

## Запуск с нуля на Windows

Нужны Windows 11 x64, полный AutoCAD 2027 и Microsoft Edge WebView2 Runtime.
Python, Node.js, ObjectARX SDK и инструменты сборки не нужны.

1. Распакуйте Windows-установщик целиком, не запускайте его из просмотра ZIP.
   Сохраните работу и закройте AutoCAD и Green Atlas.
2. Запустите `Install-GreenAtlas.cmd` двойным щелчком. Он вызывает
   PowerShell-установщик для текущего пользователя. При ошибке окно остаётся
   открытым с пояснением. Системная политика выполнения скриптов не меняется.
3. Полностью распакуйте общий `Kustanayskaya-CAD.zip`, сохранив папки и подосновы.
   Откройте генплан по пути из шага 3 Mac-сценария и проверьте XREF.
4. Выполните `GAOPEN`. При предупреждении о неподписанном плагине проверьте
   путь к установленному `GreenAtlasBridge.arx` и выберите `Load Once`.
5. Проверьте предложения по слоям, выберите рабочую границу, подготовьте карту,
   создайте участок и сохраните посадки. Для неизменённой Кустанайской предложения
   Luna включены в пакет; личного ключа OpenAI в нём нет.
6. Первый CAD-выпуск создавайте с открытым исходным сеансом AutoCAD.
   Скачайте ZIP, распакуйте целиком и откройте `planting-plan.dwg` с подосновами.

Плагин и приложение устанавливаются в
`%APPDATA%\Autodesk\ApplicationPlugins\GreenAtlas.bundle`, проекты хранятся в
`%LOCALAPPDATA%\Green Atlas\Workspace`. Предыдущий пакет сохраняется для отката.
Исходные DWG и рабочая база не перезаписываются. Подробная инструкция находится
в `README.md` внутри Windows-ZIP. AutoCAD и WebView2 устанавливаются отдельно;
если отсутствует WebView2, установите Microsoft Edge WebView2 Runtime и повторите запуск.

В архиве чистая сборка `9911969335a94c908d657cb9d4cd80ad` из коммита `8227e64`.
Все 361 файл bundle проверены по размерам и SHA-256 manifest при публикации.
По проверке Windows-ветки на стенде выполнены установка bundle, GAOPEN,
подготовка 124 слоёв, одна ручная и три автоматические посадки, скачивание
CAD-выпуска и открытие его DWG в AutoCAD 2027. Внешний ZIP перепаковывает этот
bundle; его установка отдельно не повторялась. На чистой Windows-машине без
среды разработки комплект пока не проверен, издательской подписи нет.
Заранее созданные проекты, рабочие базы и ключи API в архив не включены.

SHA-256 Windows-архива: `927e4366b95fae90503ace4ab9020c19bad3c8139fc3d508fa0322a618c003bc`.
