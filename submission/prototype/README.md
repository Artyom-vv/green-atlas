# Прототип Green Atlas: Кустанайская улица

Проверочный комплект для macOS 26, Apple Silicon и AutoCAD 2027. В публичной
версии лежат приложение с плагином и исходный код, но нет конкурсных DWG:
их публичное распространение не подтверждено.
Проект Green Atlas заранее не создан: его создаёт пользователь при открытии
чертежа. Для Windows требуется отдельная сборка и проверка с AutoCAD 2027.

## Запуск с нуля

1. Подготовьте полученный от организаторов комплект Кустанайской: генплан и
   связанные DWG должны оставаться в одной структуре папок, чтобы сохранились
   относительные пути внешних ссылок. Если исходного комплекта нет, путь от
   AutoCAD до посадок на этой улице воспроизвести нельзя.
2. Распакуйте [GreenAtlas-AutoCAD-Mac-0.1.42.zip](GreenAtlas-AutoCAD-Mac-0.1.42.zip).
   Закройте AutoCAD и Green Atlas, затем откройте `Green Atlas Installer.app`.
   Он устанавливает приложение и плагин для текущего пользователя, не меняя
   исходные чертежи.
3. В AutoCAD откройте
   `Кустанайская/05_10004141_Генплан_Кустанайская ул. - Standard/05_10004141_Генплан.dwg`.
   Проверьте состояние XREF и выполните команду `GAOPEN`. Green Atlas создаст
   локальный проект из отдельной копии чертежа.
4. В Green Atlas проверьте предложения Luna. Для DWG из этого архива
   сохранены только предложения модели, не подтверждения из другого проекта:
   ключ OpenAI для просмотра предложений не нужен. Однозначные роли сервис
   принимает автоматически; оставшиеся показываются для проверки.
   Выберите границу территории и нажмите «Подготовить карту».
   Замечания об отсутствующих объектах или XREF
   остаются замечаниями, а не автоматически считаются свободной площадью.
5. На карте создайте и сохраните рабочий участок. Откройте размещение посадок,
   выберите вид растений, количество и параметры размещения.
6. Нажмите «Найти места». Приложение покажет найденное количество и вид.
   Это предпросмотр: план ещё не меняется. Нажмите «Добавить», чтобы сохранить
   предложение, затем откройте проект повторно и проверьте посадки.
7. При необходимости создайте отдельный CAD-выпуск из интерфейса. Он не
   перезаписывает исходный DWG.

Скрипт `scripts/demo/prepare_kustanayskaya.py` нужен только разработчику для
сверки контрольных сумм и создания рабочей копии из официального датасета.
Он не объединяет здания, не замыкает контуры и не изменяет геометрию. Для
работы приложения запускать его не нужно.

## Исходные данные

Для проверенного сценария использовались десять DWG Кустанайской: основной
генплан и связанные CAD-подосновы. Они не входят в публичный репозиторий.
Сверить собственный комплект с контрольными суммами можно по
`fixtures/cad/kustanayskaya/manifest.json`. Даже с этими файлами часть XREF
может отсутствовать; приложение должно показать адресное замечание.

## Статус проверки

На новом проекте Кустанайской проверены импорт через плагин, предложения Luna
для 124 слоёв, их подтверждение и подготовка карты. На отдельной копии этого
проекта через интерфейс сохранена автоматическая посадка; после повторного
открытия проекта отображаются семь посадок. Полный путь от установки этого
комплекта на чистом Mac до нового проекта с посадками пока не подтверждён.
Тот же исполняемый файл, что установлен вместе с приложением, дополнительно
проверен в изолированном сеансе: он выполнил автоподбор на подготовленной
Кустанайской, сохранил результат и прочитал посадки после перезапуска. Эта
проверка подтверждает расчёт и хранение в сборке, но не заменяет полный прогон
кликами в установленном окне.
В установленном приложении дополнительно проверены сборка чернового выпуска,
сохранение полного ZIP и отдельной ведомости CSV. Это не проверка выпуска на
чистом компьютере организаторов.
Автоматический выбор вида временно скрыт в интерфейсе. Он не служит резервным
способом обхода ограничений: оба сценария используют одну область поиска.
Предложение не сохраняется без нажатия «Добавить».

Mac-сборка подписана тестово и не заверена Apple. На другом Mac защита системы
может остановить запуск. Для обычной публичной установки нужны Developer ID,
нотариальное заверение и проверка на чистом компьютере.
