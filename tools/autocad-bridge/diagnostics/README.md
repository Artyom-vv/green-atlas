# Изолированная диагностика AutoCAD

Скрипты этого каталога проверяют отдельные свойства захвата и Core.
Они не заменяют пользовательский вход `GAOPEN` и не квалифицируют весь продукт.

- `core_intake_run.py`: диагностическая подготовка сохранённого CAD через Core.
- Native probe/self-test: проверка извлечения, экземпляров, XREF и точности.
- Сравнение результатов: исходные и восстановленные объекты, хеши и пропуски.

Используйте копии исходников и отдельный профиль. Не сохраняйте изменения
в исходные DWG и не направляйте диагностические операции в рабочую базу.
Точные параметры конкретного CLI проверяйте через его `--help` и исходный файл.
В Windows перед каждой командой подключайте `scripts/windows-env.ps1`.

Результаты прогонов и локальные пути остаются вне Git. Отчёт должен разделять
исходный runtime, упакованный runtime и реально установленное приложение.
Код выхода 0 не заменяет контроль результатов и завершения собственного дерева.
