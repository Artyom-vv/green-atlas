# Установка Green Atlas 0.1.133

[Пошаговая инструкция и ссылка на EXE](../../../submission/prototype/README.md).
Поддерживаемый комплект: Windows 11 x64 и полный AutoCAD 2027 x64.
Для детальных моделей и рендера — Blender 4.5 LTS, Botaniq/PBR.

1. Закройте AutoCAD и Green Atlas. Запустите Setup обычным пользователем.
2. Укажите компоненты и ресурсы; их можно подключить позже кнопкой «Компоненты».
3. Завершите мастер и запустите приложение.
4. В AutoCAD откройте DWG/DXF и выполните `GAOPEN`.

Python, Node.js, PowerShell и SDK конечному пользователю не нужны.
AutoCAD/Blender и библиотеки не входят в Setup. Windows может запросить доверие
к плагину; неподписанный кандидат может вызвать предупреждение SmartScreen.

Если общий WebView2 устарел, включённый установщик Microsoft может запросить
UAC для его обновления. Сам Green Atlas устанавливается обычным пользователем.

Программа: `%APPDATA%\Autodesk\ApplicationPlugins\GreenAtlas.bundle`.
Профиль: `%LOCALAPPDATA%\GreenAtlas`; обновление и удаление его сохраняют.
Пути внешних компонентов сохранены отдельно в `Green Atlas\external-tools.json`
под LOCALAPPDATA. Не очищайте эти данные при ошибке установки.

При занятом файле закройте удерживающие процессы и повторите действие.
Удаление: «Параметры → Приложения → Green Atlas → Удалить».
